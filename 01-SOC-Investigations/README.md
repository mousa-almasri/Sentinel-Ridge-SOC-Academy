# SOC Investigations

This directory contains hands-on Security Operations Center (SOC) investigations completed as part of the Sentinel Ridge SOC Academy.

## Objectives

- Practice SOC Tier 1 and Tier 2 alert triage and security investigations.
- Analyze SIEM alerts and correlate endpoint, authentication, and network logs.
- Identify suspicious activity and evaluate potential false positives.
- Map relevant activity to the MITRE ATT&CK framework.
- Develop incident timelines, preserve evidence, and document findings.
- Practice incident escalation and response recommendations.

## Investigation Tools

- Wazuh SIEM
- Linux security logs and journalctl
- Windows Event Logs (planned)
- Network analysis tools
- Threat intelligence and OSINT resources
- AI-assisted analysis with independent evidence verification

All investigations are performed in an authorized training environment. Published evidence will be synthetic or appropriately sanitized. Credentials, private keys, sensitive personal information, and confidential employer data will not be published.
